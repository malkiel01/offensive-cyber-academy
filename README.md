# אקדמיית סייבר התקפי

מאגר התשתית של אקדמיית לימוד אישית בתחום אבטחת מידע וסייבר התקפי.

## ארכיטקטורה
- ChatGPT Projects: ניהול, הוראה ותרגול.
- GitHub: תוכנית, החלטות, גרסאות ומעקב אחר התקדמות.
- Google Drive: ספריית חומרי לימוד ומקורות.

## סטטוס
